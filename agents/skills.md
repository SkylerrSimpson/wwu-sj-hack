# Skills

Installed for everyone (`mattpocock-skills` and `ponytail`). Without them, the sentence after each colon is the procedure. Never run `/setup-matt-pocock-skills`: this file is the wiring.

- Kickoff, `/mattpocock-skills:grilling`: `kickoff.md` carries the questions; ask them one at a time until the owner says stop. Also before accepting or changing a plan.
- Core logic, `/mattpocock-skills:tdd`: one failing test, the code that passes it, repeat. TypeScript in `lib/` and Python transforms in `build.py` alike.
- 14:00 freeze, two hours before the deadline, `/mattpocock-skills:code-review` (not the built-in `/code-review`): review `git diff 90ab845..main`, the starter commit to now, against `standards.md` and against the demo script and safeguards table in `docs/SPEC.md`; each finding is a `bug` issue; then fixes only.
