# Skills

Installed for Skyler. Without them, the sentence after each colon is the procedure.

- Friday night, `/grilling`: `kickoff.md` carries the questions; ask them one at a time until the owner says stop.
- Core logic, `/tdd`: one failing test, the code that passes it, repeat.
- Saturday 5pm freeze, `/code-review`: review `git diff friday..main` against `standards.md` and against the demo script and safeguards table in `docs/SPEC.md`; each finding is a `bug` issue; then fixes only.
